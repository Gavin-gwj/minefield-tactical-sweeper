# MINE//FIELD

一台现代战术扫雷终端。纯 HTML / CSS / JavaScript，无构建步骤，可直接部署到任意静态托管平台。

## 玩法

| 操作 | 行为 |
| --- | --- |
| 左键 / Enter / Space | 翻开格子 |
| 右键 / F | 标记或取消地雷 |
| 双击 / X | 数字周围和弦展开 |
| 方向键 | 移动键盘准星 |
| 触屏长按 | 标记地雷 |

## 功能

- 首击安全区，第一下不会踩雷
- 零雷区域自动连开
- 新兵、战术、专家三档经典难度
- 每日固定种子挑战
- 本地最佳时间、胜局数和连胜记录
- 实时合成音效，无外部音频文件
- 键盘、鼠标、触屏与减少动态效果偏好支持
- 响应式布局，专家棋盘可横向滚动

## 本地运行

直接打开 `index.html`，或启动任意静态服务器：

```powershell
npx serve .
```

## 部署

仓库根目录包含 `vercel.json`。在 Vercel 中导入仓库即可自动识别为静态站点，无需构建命令。
